Confidential AI is made possible thanks to confidential computing. Confidential VMs aim to protect private guest memory from the host operating system and hypervisor, reducing the software your workload must trust. The guest software and the platform’s trusted hardware and firmware remain part of that trust boundary.

Confidential AI applies this protection to AI workloads. By running the model and its supporting software inside the protected environment, it shields sensitive inputs, model weights, and outputs from the host operating system and hypervisor while they are being processed. For GPU-accelerated workloads, that protection must extend to the GPU and the data exchanged with it.

Enterprise-ready confidential computing in Ubuntu 26.04 LTS

Ubuntu 26.04 LTS is the first enterprise Linux distribution to support both Intel TDX and AMD SEV-SNP across host and guest. Deploy confidential VMs on your own infrastructure with an integrated virtualization stack, protecting sensitive data during processing with hardware-backed isolation.

New confidential computing features without leaving LTS

Ubuntu 26.04 LTS’s optional virtualization Hardware Enablement (HWE) stack updates QEMU, libvirt and VM firmware every six months during the LTS’s first two years. It complements kernel HWE, bringing newer capabilities as they mature without requiring an upgrade to a new Ubuntu release.
