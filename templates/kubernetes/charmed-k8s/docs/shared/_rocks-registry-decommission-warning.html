Registry update:

The rocks.canonical.com registry is now a temporary service and will be retired in early 2027. ghcr.io/canonical/cdk is the only supported registry going forward and is the default for new deployments of Charmed Kubernetes 1.36 and later. Existing clusters that still use rocks.canonical.com must be updated by setting image-registry on each charm that uses Canonical images. See the list of affected charms.

To update a charm, run the following command for each charm in the list:

juju config <charm-name> image-registry=ghcr.io/canonical/cdk

If you encounter any issues, you can reach us via the support channels.
